# FinanceiroGuys

Gestão financeira pessoal para registrar receitas e despesas, acompanhar contas e planejar gastos.

O projeto está em planejamento. Este repositório reúne o escopo do MVP, as decisões técnicas e o fluxo de trabalho da equipe. A aplicação será implementada nas issues.

## O que vamos entregar

- Cadastro, login, sessão e perfil.
- Contas, saldos, extratos e transferências.
- Categorias, receitas e despesas com filtros e correções.
- Orçamentos mensais e despesas por categoria.
- Metas com aportes declarados e histórico.
- Recorrências mensais confirmadas pelo usuário.
- Dashboard com indicadores do período.

Cada integrante assume um módulo completo: interface, API, banco, testes e documentação. As responsabilidades I1–I5 serão associadas aos usuários da equipe quando a divisão for confirmada.

## Base técnica proposta

React e TypeScript no frontend; NestJS no backend; PostgreSQL com Prisma; API REST documentada com OpenAPI. A aplicação será um monólito modular, em um monorepositório.

Os comandos de instalação e execução serão adicionados quando a estrutura executável estiver pronta. Não há aplicação funcional nesta entrega inicial.
